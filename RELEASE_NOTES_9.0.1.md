# Sovereign Sol 9.0.1 — The Free Lane Holds

This is a focused reliability release.

- Hosted conversation works without requiring personal API keys.
- NVIDIA Nemotron is the fast default, with one bounded OpenCode fallback.
- Six free model choices remain available in Settings.
- Stale local quota data can no longer permanently block conversation.
- Provider credentials remain on the server and are not compiled into the APK.

This release does not claim a new Adventure mode. Companion is currently a
smaller Hearth experience and needs a separate product pass before Adventure is
presented as a release feature again.
